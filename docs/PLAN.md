# WorldViewer 개발 계획

기준일: 2026-09-23
기준 문서: [`../worldviewer-blueprint-v0.1.md`](../worldviewer-blueprint-v0.1.md)

이 계획은 앱 구현 전 기준선이다. 단계 번호는 의존 순서이며, 한 번에 한 작업만 진행한다. 1단계에서 앱 셸을 만든 뒤에는 각 작업이 설치·실행 가능한 상태와 검증 기록을 남긴다.

상태 표기는 `예정` / `진행 중` / `검증 대기` / `완료` / `보류`를 사용한다. 구조나 사용성 검증에 실패하면 완료 조건을 낮추지 않고 현재 단계를 수정한다. 단계 분할이나 순서 변경 사유는 `STATUS.md`에 기록한다.

## 요구사항 기준선

### 확정 요구사항

청사진에서 사용자와 합의된 것으로 표시된 범위는 다음과 같다.

| 영역 | 확정 범위 |
| --- | --- |
| 플랫폼 | Android 휴대폰·태블릿 우선, 향후 공개 배포 고려 |
| 독서 | TXT 가져오기, 책장, 스타일·테마, 목차, 진행률 이동, 검색, 읽던 위치 저장 |
| 언어 표시 | 중국어 원문 보기와 성조 포함 병음 보기 전환 |
| 선택 | 중국어 한 글자 단위 선택·드래그 확장·범위 수정, 영어 단어 단위 기본 선택 |
| 조회 | 사용자가 요청할 때 조회, 저장한 뜻 재사용, 직접 정의, 구간·책·전체 범위 적용 |
| 주석·보존 | 수동 목차, 메모, 책갈피, 강조, 백업·복원 |
| 제외 | 펜·자유 필기, v1의 원문 직접 편집 |

위 표는 기능 존재 여부를 확정한다. 화면 배치, 라이브러리, 데이터 공급원, 성능 수치와 구현 순서는 확정하지 않는다.

확정 요구끼리 직접 충돌하는 항목은 찾지 못했다. 다만 다음 범위는 구현 순서를 정하려면 해석이 필요하다.

- 영어 단어 선택은 확정 요구지만 청사진의 첫 정식 버전 제안은 중국어→한국어를 우선한다. 영어 선택을 v1 필수로 둘지 후속 전달물로 둘지 정해야 한다.
- 한국어 뜻 조회는 필요한 기능이지만 공급원은 미확정이다. 합법적인 공급원을 확보하기 전까지 직접 정의와 저장한 뜻만 실제 완료로 인정한다.
- 휴대폰·태블릿 지원은 확정이지만 모든 단계에서 두 폼 팩터를 동시에 완성한다는 뜻은 아니다. 핵심 실험은 휴대폰에서 시작하고 v1 수용 전 태블릿을 검증한다.
- 공개 배포는 목표이지 현재 승인된 배포 작업은 아니다. 앱 ID·서명·스토어 등록·개발자 확인은 배포 단계에서 별도로 확정한다.

### 검증 후 확정할 제안

| 제안 | 필요한 검증 |
| --- | --- |
| Kotlin 네이티브 Android | 첫 셸 프로젝트의 빌드·설치와 의존성 크기 확인 |
| View/Compose/custom View 중 읽기 렌더러 | 긴 문단, 병음, 문자 위치 판정, 접근성, 스크롤 프레임을 같은 fixture로 비교 |
| 350ms부터 시작하는 정밀 선택 제스처 | 250/350/450ms 및 시스템 길게 누르기의 오선택·선택 시간·피로도 실기기 비교 |
| 수동 조회 기본값 | 사용자 흐름 검증. 선택·드래그 네트워크 0회는 유지 |
| 중국어→한국어 우선 개발 | 영어 선택을 어느 릴리스의 완료 조건으로 둘지 결정 |
| Room/SQLite와 파일 본문 분리 | 가져오기·앵커·마이그레이션 spike로 확인 |
| 캐시 30MB, PSS 150MB, 설치 30MB 등 수치 | 기준 기기와 릴리스 유사 빌드로 측정 후 조정 |
| 하단 선택 패널을 휴대폰·태블릿 공통 시작점으로 사용 | 큰 글꼴, TalkBack, 회전, 태블릿에서 사용성 확인 |

### 제품 결정

| 결정 | 상태 | 근거·결정 시점 |
| --- | --- | --- |
| 최소 Android 버전(`minSdk`) | API 26으로 결정 | Android 8 이상을 지원하는 초기 기준. Galaxy Z Flip4의 현재 OS/API에서도 설치를 직접 확인할 예정 |
| 빌드 대상 | `compileSdk`/`targetSdk` 36으로 결정 | 설치된 SDK와 2026-08-31 이후 Google Play 신규 앱 요구사항에 맞춤 |
| 영어 범위 | 미정 | v1 구조는 확장 가능하게 유지하고 실제 완료 시점은 중국어 핵심 흐름 전에 결정 |
| 중국어→한국어 뜻 공급 방식 | 승인(2026-09-23) | v1 보장 기능은 사용자 정의·저장한 뜻으로 두고, 한국어기초사전 텍스트는 별도 표시하는 선택적 보조 자료로만 검토. 온라인 번역은 비용·본문 전송·비밀 키 관리 합의 전 도입하지 않음 |
| 앱 ID와 배포 이름 | 개발용 `dev.worldviewer`; 영구 ID 미정 | 공개 서명·배포 전에 확정 |
| 기준 실제 기기 | Galaxy Z Flip4(SM-F721N), Android 16/API 36 | 사용자 주 사용 휴대폰. 이후 가능하면 4GB RAM급 기기와 태블릿 추가 |

### 4. 병음 배치 실험판

- 포함: 라이선스가 검토된 후보 엔진으로 현재/인접 블록 비동기 변환, 원문만/전체/선택 병음 전환, 원문 앵커 유지, 다음자 수동 수정의 임시 흐름.
- 제외: 책 전체 선변환, 발화 변조 완성, 미검토 데이터 번들, 사용자 사전 영구 적용.
- 승인 결정(2026-09-23): 기본 읽기는 Unicode 17.0 Unihan `kMandarin`을 고정 버전·해시·Unicode License v3 고지와 함께 오프라인으로 사용한다. 미등록 문자는 원문을 보존하고, 문맥 다음자와 인명은 별도 수동 수정 계층으로 다룬다. 출처가 섞인 대형 구문 데이터는 이번 단계에 자동 포함하지 않는다.

- 완료 조건: 사용자가 버튼을 눌렀을 때만 요청하고, 기본 독서는 비행기 모드에서 정상이며 공급원 조건을 앱과 저장 정책이 지킨다.
- 검증: 네트워크 로그 0회/1회 수용 시나리오, 느린 응답 A가 선택 B를 덮지 않는 테스트, 캐시 만료·출처 표시·오프라인 실제 확인.

- [x] `완료` 문서·선택 버전, 결과 유형, 출처와 저장 정책을 포함하는 공급원 중립 조회 계약
- [x] `완료` 명시적 요청 전 0회 호출, 취소와 늦은 A 응답 거부를 가짜 공급원으로 검증

### 11. 백업·복원

- 포함: 버전 있는 묶음, 원문 포함 선택, 체크섬, 미리보기, 충돌 처리, 원자적 복원, 허용되지 않은 외부 캐시 제외.
- 제외: 클라우드 동기화, 계정, 자동 업로드.
- 완료 조건: 새 설치 상태에서 위치·주석·사용자 뜻·책 설정이 대조 일치하고 실패한 복원이 기존 데이터를 손상하지 않는다.
- 검증: 왕복 fixture, 손상/구버전/중복 백업, 복원 중 중단, 실제 기기 앱 데이터 초기화 뒤 수동 대조.

- [x] `완료` 손상 payload·추가 항목·미지원 버전·앱 데이터 내부 출력·생성 중단 거부와 기존 백업 보존

## 계획 변경 규칙

- 작업 중 발견한 아이디어는 나중에 할 목록에 기록하고 현재 완료 조건에 자동 추가하지 않는다.
- 단계는 필요하면 더 작은 설치 가능한 작업으로 나누되, 사용자 데이터 계약을 깨뜨리며 속도를 내지 않는다.
- 사용성·성능·권리 검증에 실패하면 다음 기능으로 넘어가기 전에 구조를 수정하거나 해당 기능을 `보류`로 명시한다.
- 완료 조건을 낮춰 단계를 완료 처리하지 않는다.
