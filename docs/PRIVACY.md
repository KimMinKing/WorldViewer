# WorldViewer 개인정보처리방침 초안

> 배포 전 초안이다. 공개 앱 이름, 개발자 이름, 연락처, 시행일과 공개 URL을 확정한 뒤 대괄호 항목을 채우고 현재 release 후보와 다시 대조해야 한다.

WorldViewer(가칭)는 중국어 TXT를 기기에서 읽고 병음, 사용자 뜻, 주석, 책갈피와 읽던 위치를 관리하는 오프라인 Android 앱이다.

## 수집과 전송

현재 버전은 개인정보나 사용 통계를 개발자에게 수집·전송하지 않는다. 계정, 광고, 분석 SDK, 원격 서버와 인터넷 권한을 사용하지 않는다. 위치, 연락처, 사진, 카메라와 마이크 권한도 요청하지 않는다.

## 기기에 저장하는 정보

사용자가 시스템 파일 선택기에서 직접 고른 TXT의 원본 바이트 사본과 파일 정보, 책 목록, 읽던 위치, 표시 설정, 수동 목차, 사용자 뜻, 주석과 책갈피를 앱 전용 저장 공간에 보관한다. 이 정보는 독서 기능과 재실행 뒤 상태 복원에만 사용한다.

앱은 Android 자동 클라우드 백업과 기기 간 자동 전송에서 앱 저장 영역을 제외한다. 사용자가 앱의 백업 기능을 실행하면 위 정보와 선택에 따라 원문 TXT를 `.wvb` 파일에 담아 사용자가 고른 위치에 저장한다.

## 시스템 파일 선택기와 외부 저장소

앱은 사용자가 시스템 파일 선택기에서 고른 TXT와 백업 파일만 읽거나 쓴다. 사용자가 Google Drive 같은 외부 저장소 공급자를 선택하면 Android와 해당 공급자가 파일을 내려받거나 업로드할 수 있으며, 이 처리는 해당 공급자의 정책을 따른다. 앱은 별도의 서버로 파일을 보내지 않는다.

## 보관과 삭제

앱 내부 정보는 사용자가 Android 설정에서 앱 데이터를 지우거나 앱을 제거할 때까지 기기에 남을 수 있다. 책장에서 항목을 제거해도 보존한 원본과 읽기 기록은 자동 삭제하지 않는다. 사용자가 외부 위치에 만든 `.wvb` 백업은 앱 데이터 삭제나 앱 제거의 영향을 받지 않으므로 해당 파일 앱이나 저장소 공급자에서 직접 삭제해야 한다.

## 아동의 개인정보

현재 버전은 계정을 만들지 않고 개인정보를 개발자에게 수집하거나 전송하지 않는다.

## 변경과 문의

앱에 온라인 사전, 번역, 동기화, 분석 또는 다른 외부 서비스가 추가되면 전송 항목, 목적, 보관 기간과 제공자를 먼저 고지하고 이 방침을 갱신한다.

- 개발자 또는 운영 주체: [배포 전 입력]
- 문의 연락처: [배포 전 입력]
- 시행일: [배포 전 입력]
- 공개 방침 URL: [배포 전 입력]
