# WorldViewer 개인정보처리방침 초안

> 배포 전 초안이다. 공개 앱 이름, 개발자 이름, 연락처, 시행일과 공개 URL을 확정한 뒤 대괄호 항목을 채우고 현재 release 후보와 다시 대조해야 한다.

WorldViewer(가칭)는 중국어 TXT를 기기에서 읽고 병음, 사전 뜻, 사용자 뜻, 주석, 책갈피와 읽던 위치를 관리하는 Android 앱이다. 기본 독서와 앱에 포함된 영어 사전 검색은 오프라인으로 동작한다.

## 수집과 전송

현재 버전은 계정과 광고를 사용하지 않으며 개발자 서버를 운영하지 않는다. 위치, 연락처, 사진, 카메라와 마이크 권한도 요청하지 않는다.

사용자가 선택한 중국어의 한국어 사전 뜻을 요청하면 앱은 CC-CEDICT의 영어 뜻을 Google ML Kit 기기 내 번역 기능으로 한국어화한다. 선택한 중국어, 영어 뜻의 내용과 번역 결과는 기기에서 처리되며 Google 서버로 전송되지 않는다. 첫 사용과 모델 갱신 때 영어↔한국어 번역 모델을 내려받기 위해 인터넷을 사용한다. Android 16 에뮬레이터에서는 모델이 약 52MB를 사용했으며 기기와 버전에 따라 달라질 수 있다.

Google의 공개 안내에 따르면 ML Kit는 모든 기능에서 기기 제조사·모델·OS·빌드와 가속기 정보, 앱 패키지·버전, 사용자를 직접 식별할 목적이 아닌 설치별 식별자, 처리 시간 같은 성능 정보, API 구성, 입력·출력의 크기, 기능·모델 버전, 초기화·모델 다운로드·번역·해제 같은 이벤트와 오류 코드를 진단·사용량 분석 목적으로 수집한다. 번역 기능은 설정한 원문·대상 언어(영어·한국어)도 수집하며 Firebase Remote Config와 Firebase Installations를 사용한다. Google은 이 데이터가 HTTPS로 암호화되어 전송되고 제3자에게 공유되지 않는다고 안내한다. 개발자는 이 데이터에 직접 접근하지 않는다. 자세한 항목은 [ML Kit Data safety 안내](https://developers.google.com/ml-kit/android-data-disclosure)와 [ML Kit 약관·개인정보 안내](https://developers.google.com/ml-kit/terms)를 따른다.

앱은 첫 모델 다운로드 전에 Wi-Fi 전용 또는 모바일 데이터 허용을 사용자가 고르게 한다. 사전 버튼을 누르지 않은 기본 독서와 선택 동작은 모델 다운로드나 번역을 실행하지 않는다.

사용자가 사전 결과의 `온라인 번역`을 누르면 첫 사용 전에 외부 전송 안내와 취소 선택을 표시한다. 동의하고 계속한 경우에만 선택한 중국어를 HTTPS로 MyMemory 운영사 Translated에 보내 중국어→한국어 자동 번역 한 개를 받는다. 책 전체, 앞뒤 문맥, 문서 이름, 읽던 위치와 사용자 주석은 보내지 않는다. 앱은 MyMemory 결과를 자동 저장하거나 개발자에게 전송하지 않는다. MyMemory는 조회문, IP 주소, 접속 시각 같은 정보를 처리하고 외부 기계번역 공급자를 사용할 수 있으며 결과와 서비스 가용성을 보장하지 않는다. 자세한 내용은 [MyMemory 약관](https://mymemory.translated.net/terms-and-conditions)과 [무료 사용 한도](https://mymemory.translated.net/doc/usagelimits.php)를 따른다.

## 기기에 저장하는 정보

사용자가 시스템 파일 선택기에서 직접 고른 TXT의 원본 바이트 사본과 파일 정보, 책 목록, 읽던 위치, 표시 설정, 수동 목차, 사용자 뜻, 주석과 책갈피를 앱 전용 저장 공간에 보관한다. 이 정보는 독서 기능과 재실행 뒤 상태 복원에만 사용한다. CC-CEDICT 검색 색인은 앱에 포함된 재생성 가능한 데이터이며, Google 번역 모델은 첫 사용 뒤 기기 저장 공간에 보관될 수 있다. 자동 번역 결과는 앱이 영구 저장하지 않으며 사용자가 직접 뜻으로 저장한 경우에만 사용자 데이터가 된다.

앱은 Android 자동 클라우드 백업과 기기 간 자동 전송에서 앱 저장 영역을 제외한다. 사용자가 앱의 백업 기능을 실행하면 위 정보와 선택에 따라 원문 TXT를 `.wvb` 파일에 담아 사용자가 고른 위치에 저장한다.

## 시스템 파일 선택기와 외부 저장소

앱은 사용자가 시스템 파일 선택기에서 고른 TXT와 백업 파일만 읽거나 쓴다. 사용자가 Google Drive 같은 외부 저장소 공급자를 선택하면 Android와 해당 공급자가 파일을 내려받거나 업로드할 수 있으며, 이 처리는 해당 공급자의 정책을 따른다. 앱은 별도의 서버로 파일을 보내지 않는다.

## 보관과 삭제

앱 내부 정보는 사용자가 Android 설정에서 앱 데이터를 지우거나 앱을 제거할 때까지 기기에 남을 수 있다. 책장에서 항목을 제거해도 보존한 원본과 읽기 기록은 자동 삭제하지 않는다. 사용자가 외부 위치에 만든 `.wvb` 백업은 앱 데이터 삭제나 앱 제거의 영향을 받지 않으므로 해당 파일 앱이나 저장소 공급자에서 직접 삭제해야 한다.

## 아동의 개인정보

현재 버전은 계정을 만들지 않고 개인정보를 개발자에게 수집하거나 전송하지 않는다. 사용자가 온라인 번역을 선택하면 위에 설명한 선택 원문과 접속 정보가 MyMemory에서 처리될 수 있다.

## 변경과 문의

앱에 다른 온라인 사전, 본문을 외부로 보내는 번역, 동기화, 광고·분석 또는 다른 외부 서비스가 추가되면 전송 항목, 목적, 보관 기간과 제공자를 먼저 고지하고 이 방침을 갱신한다.

- 개발자 또는 운영 주체: [배포 전 입력]
- 문의 연락처: [배포 전 입력]
- 시행일: [배포 전 입력]
- 공개 방침 URL: [배포 전 입력]
