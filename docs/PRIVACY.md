# WorldViewer 개인정보처리방침 초안

> 배포 전 초안이다. 공개 앱 이름, 개발자 이름, 연락처, 시행일과 공개 URL을 확정한 뒤 대괄호 항목을 채우고 현재 release 후보와 다시 대조해야 한다.

WorldViewer(가칭)는 중국어 TXT를 기기에서 읽고 병음, 번역·사용자 뜻, 주석, 책갈피와 읽던 위치를 관리하는 Android 앱이다. 기본 독서와 저장한 사용자 뜻 조회는 오프라인으로 동작한다.

## 수집과 전송

현재 버전은 계정과 광고를 사용하지 않으며 개발자 서버를 운영하지 않는다. 위치, 연락처, 사진, 카메라와 마이크 권한도 요청하지 않는다.

Azure 자격 증명이 없는 사용자가 설정 화면에서 `MyMemory 짧은 번역`을 선택하면 첫 사용 전에 외부 전송 안내와 취소 선택을 표시한다. 동의하고 계속한 경우에만 선택한 중국어를 HTTPS로 MyMemory 운영사 Translated에 보내 중국어→한국어 자동 번역 한 개를 받는다. 책 전체, 앞뒤 문맥, 문서 이름, 읽던 위치와 사용자 주석은 보내지 않는다. 앱은 MyMemory 결과를 자동 저장하거나 개발자에게 전송하지 않는다. MyMemory는 조회문, IP 주소, 접속 시각 같은 정보를 처리하고 외부 기계번역 공급자를 사용할 수 있으며 결과와 서비스 가용성을 보장하지 않는다. 자세한 내용은 [MyMemory 약관](https://mymemory.translated.net/terms-and-conditions)과 [무료 사용 한도](https://mymemory.translated.net/doc/usagelimits.php)를 따른다.

사용자가 Azure Translator를 설정하면 앱은 Key1과 지역을 휴대폰 앱 전용 영역에 저장하되, Key1과 지역의 묶음은 Android Keystore의 내보낼 수 없는 키로 AES-GCM 암호화한다. Key2와 별도 Endpoint 입력은 사용하지 않는다. 사용자가 선택 도구의 `Azure 번역`을 누른 경우에만 선택한 중국어를 HTTPS로 Microsoft Azure Translator 공용 Endpoint에 보내고 한국어 결과를 받는다. 책 전체, 선택하지 않은 앞뒤 문맥, 문서 이름, 읽던 위치와 주석은 보내지 않으며 결과를 자동 저장하지 않는다. 결과 화면에서 사용자가 `뜻 추가`를 누른 경우에만 사용자 데이터로 저장한다. Microsoft는 표준 텍스트 번역에 제출한 고객 데이터를 보관하지 않는다고 안내한다. 자세한 내용은 [Azure Translator 데이터·보안 안내](https://learn.microsoft.com/azure/ai-services/translator/secure-deployment)를 따른다.

## 기기에 저장하는 정보

사용자가 시스템 파일 선택기에서 직접 고른 TXT의 원본 바이트 사본과 파일 정보, 책 목록, 읽던 위치, 표시 설정, 수동 목차, 사용자 뜻, 주석과 책갈피를 앱 전용 저장 공간에 보관한다. 이 정보는 독서 기능과 재실행 뒤 상태 복원에만 사용한다. 자동 번역 결과는 앱이 영구 저장하지 않으며 사용자가 `뜻 추가`를 누른 경우에만 사용자 데이터가 된다.

앱은 Android 자동 클라우드 백업과 기기 간 자동 전송에서 앱 저장 영역을 제외한다. 사용자가 앱의 백업 기능을 실행하면 위 정보와 선택에 따라 원문 TXT를 `.wvb` 파일에 담아 사용자가 고른 위치에 저장한다.

## 시스템 파일 선택기와 외부 저장소

앱은 사용자가 시스템 파일 선택기에서 고른 TXT와 백업 파일만 읽거나 쓴다. 사용자가 Google Drive 같은 외부 저장소 공급자를 선택하면 Android와 해당 공급자가 파일을 내려받거나 업로드할 수 있으며, 이 처리는 해당 공급자의 정책을 따른다. 앱은 별도의 서버로 파일을 보내지 않는다.

## 보관과 삭제

앱 내부 정보는 사용자가 Android 설정에서 앱 데이터를 지우거나 앱을 제거할 때까지 기기에 남을 수 있다. 책장에서 항목을 제거해도 보존한 원본과 읽기 기록은 자동 삭제하지 않는다. 사용자가 외부 위치에 만든 `.wvb` 백업은 앱 데이터 삭제나 앱 제거의 영향을 받지 않으므로 해당 파일 앱이나 저장소 공급자에서 직접 삭제해야 한다.

## 아동의 개인정보

현재 버전은 앱 계정을 만들지 않고 개인정보를 개발자에게 수집하거나 전송하지 않는다. 사용자가 온라인 번역을 선택하면 위에 설명한 선택 원문과 접속 정보가 Azure Translator 또는 사용자가 선택한 MyMemory에서 처리될 수 있다.

## 변경과 문의

앱에 다른 온라인 사전, 본문을 외부로 보내는 번역, 동기화, 광고·분석 또는 다른 외부 서비스가 추가되면 전송 항목, 목적, 보관 기간과 제공자를 먼저 고지하고 이 방침을 갱신한다.

- 개발자 또는 운영 주체: [배포 전 입력]
- 문의 연락처: [배포 전 입력]
- 시행일: [배포 전 입력]
- 공개 방침 URL: [배포 전 입력]
